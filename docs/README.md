# AIL Documentation

Welcome to the **AIL** (*AI Language*) documentation set.

## Reading Order

1. **[Programming Guide (`GUIDE.md`)](GUIDE.md)** — Start here. Covers installation, typed `$kind[:name]` resource registries, `expect config`, core Ruby-inspired syntax, multi-file `require`, schemas, sandboxed tools, guardrails, append-only `Context` views, `within budget`, agents & live streaming, MCP servers/clients, Agent Skills (`SKILL.md`), System 1 `decide`, stateful `flow` graphs, `Knowledge` RAG, `a2a_agent`, `ail repl`, and `ail debug`.
2. **[Class & Type Reference (`CLASSES.md`)](CLASSES.md)** — Self-contained reference for every class, built-in type, module, AI runtime object, and exception in AIL (written completely in AIL terms, including runtime guarantees like sandboxing, deadlines, decimals, and regexes).
3. **[Standard Library & Config Reference (`STDLIB.md`)](STDLIB.md)** — Quick cheat sheet and `.ail.env` driver configuration reference.
4. **[Worked Examples Index (`EXAMPLES.md`)](EXAMPLES.md)** — Quick lookup table of every runnable example in [`../examples/`](../examples/README.md) with copy-paste commands.
5. **[Language Specification (`SPEC.md`)](SPEC.md)** — High-level specification of the resource model, core language, first-class AI constructs, and milestone history (`v0.1.0`–`v0.5.0`).

# AIL Documentation

Welcome to the **AIL** (*AI Language*) documentation set.

## Reading Order

1. **[Programming Guide (`GUIDE.md`)](GUIDE.md)** — Start here. Covers installation, `.ail.env` configuration, core Ruby-inspired syntax, multi-file `require`, schemas, sandboxed tools, guardrails, append-only `Context` views, `within budget`, agents & live streaming, MCP servers/clients, Agent Skills (`SKILL.md`), System 1 `decide`, stateful `flow` graphs, `Knowledge` RAG, `a2a_agent`, `ail repl`, and `ail debug`.
2. **[Standard Library & Runtime Reference (`STDLIB.md`)](STDLIB.md)** — Complete method-by-method reference for built-in types (`String`, `Array`, `Hash`, `Range`, `Regex`, `Int`/`Float`/`Decimal`/`Duration`), stdlib modules (`File`, `JSON`, `Env`, `Time`, `Math`, `Random`), AI runtime classes (`Context`, `Knowledge`, `MCP`, `Config`, `Agent`, `Flow`), exceptions, and `.ail.env` driver schemas.
3. **[Worked Examples Index (`EXAMPLES.md`)](EXAMPLES.md)** — Quick lookup table of every runnable example in [`../examples/`](../examples/README.md) with copy-paste commands.
4. **[Language Specification (`SPEC.md`)](SPEC.md)** — High-level specification of the resource model, core language, first-class AI constructs, and milestone history (`v0.1.0`–`v0.5.0`).
